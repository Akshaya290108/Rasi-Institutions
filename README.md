# 🎓 Rasi Institutions – Educational Website

Welcome to the **Rasi Institutions Website** — a modern, responsive, and visually attractive educational website designed to showcase an institution's academic programs, campus facilities, faculty, events, and contact information.

The website uses a clean **light sky-blue and white theme**, modern typography, attractive cards, icons, animations, and responsive layouts to provide an engaging user experience.

## 🌐 Project Overview

**Rasi Institutions** is a front-end web development project created to demonstrate a professional institutional website.

The website includes multiple interactive sections:

* 🏠 Home
* 🏛️ About Us
* 📚 Courses
* 🤖 AI Campus
* 👨‍🏫 Faculty
* 📅 Events
* 📩 Contact

The navigation system allows users to switch between sections smoothly without leaving the main webpage.

## 📱 Responsive Design

The website is designed to work across different screen sizes, including:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

Responsive CSS rules automatically adjust the navigation, cards, hero section, and statistics layout for smaller screens.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Locate `home.html`.
4. Double-click `home.html` or open it using a web browser.
5. Explore the different sections using the navigation menu.

No server or database is required because this is a front-end project.
